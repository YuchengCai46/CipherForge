📖 使用说明

🔐 CipherForge 是什么？

一个开源的桌面级密码学工具箱，提供对称加密、哈希计算、密码生成、Shamir 秘密共享等实用功能。

🚀 快速开始

  • 点击顶部导航栏切换不同功能模块
  • 填写表单后点击「执行」按钮完成操作
  • 所有计算结果支持一键复制到剪贴板
  • 点击右上角 🌙 按钮可切换深色/浅色主题

⚛️ 抗量子签名（PQ）

当前环境已自动安装备用后端 dilithium-py，ML-DSA-87 签名功能可直接使用。如需完整支持 FALCON 和 SLH-DSA 算法，请安装 liboqs：

pip install liboqs-python

⚠️ liboqs 需要 CMake 和 C 编译器，安装较复杂。

🔒 对称加密

AES-256-GCM、ChaCha20-Poly1305、XChaCha20、Serpent、Twofish 等 AEAD 算法。输入明文+密码即可加密，结果包含密文、Nonce、Tag。

🔓 对称解密

使用相同的算法、密码、Nonce 和 Tag 解密密文，自动验证完整性。

🧅 级联加密

多层嵌套加密，每层独立盐+独立密码。可选算法层顺序，最大增强安全性。

#️⃣ 哈希计算

SHA-256/384/512、SHA3、BLAKE2b/s 等算法。输入任意数据即时计算哈希。

🔑 密码生成

支持随机字符（含符号）和 Diceware 密语两种模式，可排除易混淆字符。

📝 Shamir 秘密共享

GF(256) 门限方案：N 份分片中取任意 T 份即可恢复秘密。适合多人保管敏感数据。

🖼️ LSB 隐写

将秘密数据隐藏到图片最低有效位，支持 1-4 位深度。当前 Web 版为演示模式。

⚛️ 抗量子签名

ML-DSA-87（Dilithium，NIST FIPS 204）已可用。FALCON 和 SLH-DSA 需要 liboqs。

🛡️ 本地安全

所有加密操作均在本地完成，密钥和明文不会上传到服务器。

🔒 最佳实践

  • 使用足够强的密码（建议 16 位以上）
  • 重要数据建议使用级联加密或多层保护
  • 定期更换密钥，不要重复使用
  • Shamir 分片应分发给可信的不同人员

📋 关于抗量子

后量子密码学（PQC）是抗量子计算机攻击的新型密码算法。NIST 已于 2024 年正式发布 ML-DSA（Dilithium）和 SLH-DSA（SPHINCS+）标准。
